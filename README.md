# Smiler

The shared look, settings and alerts for Tom's add-ons: SmilerKeys, CD Timeline, RampNotes, DiedTo, Rewound and LustReady.

- `/smiler` opens one settings window with a tab per add-on. Each tab can turn its add-on off completely (after a reload), which is the real saving in memory and CPU.
- One button in the add-on menu by the minimap: click for your add-ons and status (lust available, friends synced, best Rewind), right-click for settings.
- All alerts share one place on screen and one size: `/smiler move`, `/smiler test`.
- Crystal Ball colours each mean one thing and always come with a shape: emerald tick = ready, diamond star = record or BiS, topaz arrow = upgrade, ruby warning = death, sapphire i = info.

Every add-on still works without Smiler; it just looks after itself then.
